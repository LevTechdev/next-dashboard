## Dark Mode Behavior

All tokens have `.dark` overrides in `globals.css`. The theme is toggled by adding/removing `.dark` class on `<html>` via `next-themes`.

**Key dark mode differences:**

- Surfaces: Lighter gray → richer near-black (`225 20% 11%`)
- Borders: Lighter gray → muted gray-white (`225 15% 26%`)
- Glass: 60% white → 80% near-black
- Glows: 6-8% opacity → 10-18% opacity (brighter on dark)
- Premium gradient: Indigo-500 → Indigo-400 (lighter for dark bg)
- Shadows: Subtle → deep (40-50% black opacity)

**Smooth transitions:** Theme toggles animate over 350ms via the `.theme-transitioning` CSS class, which transitions `background-color`, `border-color`, `color`, `box-shadow`, `background-image`, `fill`, and `stroke` across all elements using `cubic-bezier(0.16, 1, 0.3, 1)`.
